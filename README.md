# RodaRaya

Landing page rental mobil dengan HTML, CSS, dan JavaScript murni.

## Menjalankan

Buka `index.html` di browser. Tidak perlu instalasi atau build tools.

## Fitur

- Pencarian mobil berdasarkan kota serta tanggal jemput dan kembali.
- Filter tipe kendaraan dan pengurutan harga.
- Form permintaan sewa dengan validasi dan ringkasan mobil.
- Tampilan responsif untuk desktop dan ponsel.

Permintaan sewa saat ini berupa demo front-end dan belum terhubung ke sistem pemesanan atau pembayaran. Foto dan font dimuat dari Unsplash dan Google Fonts, jadi koneksi internet diperlukan untuk menampilkan aset tersebut.
